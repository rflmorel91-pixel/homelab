## Delivery approach

**Assess → Scope → Implement → Test → Accept → Hand off**

Operating principles:

- Fixed and documented scope
- Clear inputs, outputs, and responsibilities
- Explicit exclusions and acceptance criteria
- Validation before deployment
- No unapproved end-client contact
- Provider retains the client relationship
- Changes outside scope are quoted separately
