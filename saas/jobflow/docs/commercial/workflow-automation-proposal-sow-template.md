## 17. Change-Control Process

A change includes any request to alter:

- Trigger, inputs, outputs, systems, owners, or volume
- Deliverables
- Integration behavior
- Data or access requirements
- Exceptions or human-review rules
- Acceptance criteria
- Schedule
- Documentation
- Training, hosting, maintenance, monitoring, or support

Change process:

1. Either party records the requested change in writing.
2. FieldLookers evaluates scope, feasibility, risk, price, and schedule impact.
3. FieldLookers provides one of:
   - Clarification that the request is already in scope
   - A written change order
   - A separate proposal
   - A written decision that the request cannot be accepted
4. No changed work begins until authorized representatives approve it in writing.
5. Any additional deposit or payment stated in the change order must be received before changed work begins.

Verbal discussion, demonstration feedback, email suggestions, or access to a system does not modify scope by itself.

Out-of-scope work is quoted separately.
