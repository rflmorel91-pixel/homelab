# Block 1 — Product Identity

## Product Name

JobFlow

## Product Type

Software as a Service (SaaS) application.

## Product Purpose

JobFlow is a workflow management platform designed for independent home-service businesses.

Core workflow:

Customer → Job → Estimate → Approval → Schedule → In Progress → Completed → Invoice → Sent → Paid

## Development Stage

Commercial software product under development.

## Product Origin

JobFlow began as a browser-based workflow prototype and is being developed into a database-backed SaaS application using:

- Frontend web application
- FastAPI backend
- PostgreSQL database
- Multi-tenant architecture
- Authentication and authorization controls
