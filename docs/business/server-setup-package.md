# Small Business Server Setup Package

## Overview

A fixed-scope infrastructure setup service for small businesses, home-based businesses, and remote workers that need a reliable Linux server for applications, file services, internal tools, or other workloads.

The service follows:

**Assess → Build → Secure → Verify → Document**

## What the Client Receives

### 1. Initial Assessment

- Review the intended server workload
- Review available hardware or virtual infrastructure
- Identify basic storage and networking requirements
- Identify required applications and services

### 2. Server Deployment

- Linux server installation or VM deployment
- Hostname and basic system configuration
- User account configuration
- SSH configuration
- Storage configuration
- Network configuration

### 3. Security Baseline

- Firewall configuration
- SSH security configuration
- Root access review
- Security update configuration
- Basic service exposure review

### 4. Application Deployment

Where applicable:

- Docker installation
- Docker Compose configuration
- Application deployment
- Service configuration
- Basic service testing

### 5. Monitoring & Health Verification

Where applicable:

- Basic resource monitoring
- Service availability checks
- System health verification
- Initial operational test

### 6. Documentation

The client receives documentation covering:

- Server configuration
- Installed services
- Network configuration
- Access information
- Backup recommendations
- Basic maintenance procedures

## Deliverables

At completion, the client receives:

- Configured server or VM
- Configured user access
- Firewall baseline
- Required application or container deployment
- Basic monitoring or health checks
- Configuration documentation
- Handoff checklist

## Scope

This starter package covers **one server or virtual machine** and a limited number of applications agreed upon before work begins.

The final scope should be confirmed during the initial assessment.

## Exclusions

The starter package does not automatically include:

- Large-scale migrations
- Complex networking redesign
- Domain controller deployment
- Enterprise identity systems
- Custom application development
- Advanced security assessments
- 24/7 monitoring
- Ongoing managed services
- Hardware purchases
- Third-party licensing costs

Additional work can be quoted separately.

## Estimated Effort

Typical starter engagements are expected to require approximately:

**3–6 hours**

Actual effort depends on the existing environment and requested services.
