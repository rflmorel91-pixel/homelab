# Client Lead & Engagement Tracker

## Purpose

This tracker is used to manage prospective clients from initial contact through assessment, quoting, delivery, and follow-up.

The workflow is:

**Lead → Contact → Assessment → Quote → Approval → Delivery → Handoff → Follow-Up**

---

## Lead Status

Use one of the following statuses:

* **New** — New prospect has been identified
* **Contacted** — Initial contact completed
* **Assessment** — Client requirements are being assessed
* **Quoted** — Quote or statement of work has been provided
* **Approved** — Client approved the work
* **In Progress** — Implementation is underway
* **Completed** — Work has been completed and handed off
* **Follow-Up** — Follow-up or additional work opportunity
* **Lost** — Opportunity did not proceed

## Follow-Up Checklist

For completed engagements:

* [ ] Confirm client satisfaction
* [ ] Confirm documentation received
* [ ] Ask whether additional infrastructure help is needed
* [ ] Identify backup requirements
* [ ] Identify monitoring requirements
* [ ] Identify security maintenance requirements
* [ ] Identify recurring support opportunities
* [ ] Request testimonial or referral where appropriate
