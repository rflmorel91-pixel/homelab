# Linux Security Hardening Package

## Overview

A fixed-scope security hardening service designed to establish a practical baseline for Linux servers and small infrastructure environments.

The service follows:

**Assess → Harden → Verify → Document**

The goal is to reduce unnecessary exposure, improve access controls, and establish a documented security baseline.

## What the Client Receives

### 1. Security Assessment

- Review the server operating system
- Review user accounts and administrative access
- Review SSH configuration
- Review firewall configuration
- Review exposed services
- Review basic security update configuration
- Identify obvious configuration risks

### 2. SSH Hardening

Where applicable:

- Review SSH configuration
- Configure secure administrative access
- Configure SSH key authentication
- Review root login settings
- Review password authentication
- Review SSH forwarding settings
- Verify SSH service status
- Test administrative access

### 3. Firewall Configuration

Where applicable:

- Configure host firewall
- Establish secure default policies
- Allow required services only
- Review existing firewall rules
- Verify required network access
- Test connectivity after changes

### 4. User & Access Review

- Review local user accounts
- Review administrative privileges
- Review sudo access
- Review SSH authorized keys
- Identify unnecessary accounts
- Review root access

### 5. System Security Baseline

Where applicable:

- Configure security updates
- Review automatic security updates
- Review unnecessary services
- Review exposed network services
- Verify system configuration
- Perform basic security validation

### 6. Verification & Documentation

The client receives documentation covering:

- Security configuration
- SSH configuration
- Firewall rules
- User access
- Security update configuration
- Exposed services
- Verification results
- Recommended maintenance actions

## Deliverables

At completion, the client receives:

- Security assessment summary
- Hardened SSH configuration
- Firewall baseline
- User and access review
- Security update configuration
- Service exposure review
- Verification results
- Security documentation
- Handoff checklist

## Scope

The starter package covers:

- One Linux server or virtual machine
- One SSH configuration
- One host firewall
- One user/access review
- Basic service exposure review
- Basic security update configuration

The exact scope should be confirmed during the initial assessment.

## Exclusions

The starter package does not automatically include:

- Penetration testing
- Vulnerability scanning at enterprise scale
- Security Operations Center services
- Malware removal
- Incident response
- Digital forensics
- Compliance certification
- Enterprise identity architecture
- Advanced network security architecture
- Application security testing
- Custom security software
- 24/7 security monitoring

Additional work can be quoted separately.
